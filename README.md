# Flatline music videos

Motion-graphics music videos for "Flatline", built with Remotion.

- `docs/project-state.md`: treatment, shot list, timings, decisions and next steps
- `data/`: beat grid and bar map extracted from the song
- `analysis/`: the one-off audio analysis scripts that produced `data/`

Media (the song, stills and renders) lives in Google Drive, not in this repo.
